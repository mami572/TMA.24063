### 🔷 TP1 — تحليل الإشارات

دراسة الإشارات الأساسية (جيبية، مربعة، مثلثية) في المجال الزمني.

**المفاهيم الأساسية:**
- توليد الإشارات باستخدام `numpy`
- التمثيل الزمني باستخدام `matplotlib`
- حساب السعة والتردد والدورة

```python
import numpy as np
import matplotlib.pyplot as plt

fe = 1000          # تردد أخذ العينات (Hz)
f0 = 10            # تردد الإشارة (Hz)
t = np.arange(0, 1, 1/fe)
x = np.sin(2 * np.pi * f0 * t)

plt.plot(t, x)
plt.title("إشارة جيبية")
plt.xlabel("الزمن (ث)")
plt.ylabel("السعة")
plt.show()
```

### 🔷 TP2 — الفلترة والتحليل الطيفي

تطبيق المرشحات الرقمية وتحليل الطيف الترددي عبر FFT.

**المفاهيم الأساسية:**
- تحويل فورييه السريع (FFT)
- المرشحات: تمرير منخفض، تمرير مرتفع، تمرير نطاق
- الاستجابة الترددية للمرشح

```python
from scipy.signal import butter, filtfilt
import numpy as np

def filtre_passe_bas(signal, fc, fe):
    """تطبيق مرشح تمرير منخفض من نوع Butterworth"""
    b, a = butter(4, fc / (fe / 2), btype='low')
    return filtfilt(b, a, signal)
```

**الوظائف الرئيسية:**

| الوظيفة | الوصف |
|---------|-------|
| `fft(signal)` | حساب الطيف الترددي |
| `butter()` | تصميم مرشح Butterworth |
| `filtfilt()` | فلترة بدون إزاحة طور |

### 🔷 TP3 — الـ Aliasing والتكميم

دراسة تأثيرات ضعف أخذ العينات والتكميم الرقمي.

**المفاهيم الأساسية:**
- مبرهنة شانون-نايكويست : `fe ≥ 2 × f_max`
- الطي الطيفي (Aliasing)
- التكميم على N بت : `2^N` مستوى
- نسبة الإشارة إلى ضوضاء التكميم (RSBQ)

```python
# توضيح ظاهرة الـ Aliasing
f_signal = 100  # Hz
fe_ok    = 500  # صحيح : fe > 2 × f_signal → لا aliasing
fe_alias =  80  # خطأ  : fe < 2 × f_signal → aliasing !
```
